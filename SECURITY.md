# Política de Seguridad (Security Policy) 🛡️

La seguridad y la privacidad de los usuarios de **Design Extractor MCP** son prioridades fundamentales. Dado que este software maneja automatización de navegadores, almacenamiento de tokens y sesiones autenticadas (como cookies de Moodle o credenciales SaaS), seguimos pautas estrictas para la divulgación responsable de vulnerabilidades.

---

## Versiones Soportadas

Actualmente brindamos soporte de seguridad y parches en las siguientes versiones:

| Versión | Soportada |
| :--- | :--- |
| **1.4.x** | ✅ Sí |
| < 1.4.0 | ❌ Se recomienda actualizar |

---

## Reportar una Vulnerabilidad

Si descubres una posible vulnerabilidad de seguridad en este proyecto:

1. **NO divulgues la vulnerabilidad públicamente** a través de un issue público de GitHub.
2. Utiliza la función privada de reporte de vulnerabilidades de GitHub (**Security Advisories** > **Report a vulnerability**) en el repositorio:
   [https://github.com/JhonnyCCM/Design-Extractor-MCP/security/advisories](https://github.com/JhonnyCCM/Design-Extractor-MCP/security/advisories)
3. Alternativamente, contacta directamente al mantenedor del proyecto vía GitHub.

### ¿Qué incluir en tu reporte?
- Descripción detallada de la vulnerabilidad.
- Pasos reproducibles o prueba de concepto (PoC).
- Impacto potencial estimado.
- Sugerencia de solución o parche si dispones de una.

### Tiempo de Respuesta
- Confirmaremos la recepción de tu reporte en un plazo máximo de **48 horas**.
- Proporcionaremos una evaluación inicial y mantendremos comunicación continua hasta que se publique una versión corregida.
